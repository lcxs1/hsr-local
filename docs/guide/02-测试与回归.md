## 3. 跑脚本

先**完全关闭游戏**（任务管理器里没有 `StarRail.exe`），然后：

```powershell
cd E:\LCXS\run\hsr-local
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\game_test.ps1
```

脚本会：

1. 检查 21000/23301 端口；
2. 用默认 `config.toml` 启动服务端；
3. 启动 firefly 代理并以管理员拉起游戏（**UAC 点“是”**）；
4. 等登录包，在登录后 **+10 / +40 / +90 秒**自动截三张全屏图；
5. 暂停，等你在游戏里手动测试；
6. 回车后写 `logs\test\<run>.report.md`、停服务端/代理、还原系统代理。

常用参数：

| 参数 | 作用 |
|---|---|
| `-ShotPlan 10,60,120,180` | 改截图时间 |
| `-NoLaunch` | 自己启动游戏 |
| `-NoGame` | 只查看步骤，不启动任何东西 |
| `-KeepServer` / `-KeepProxy` | 结束后保留服务端/代理 |
| `-PatchPrefs` | 对照客户端 prefs（登录后会被覆盖，通常不需要） |

## 4. 手动测试步骤

脚本暂停后（三张图已拍完）：

1. **出生点**：人物是否站在凝滞虚影上；退出重登一次，确认还是同一位置。
2. **战斗 + 再来一次**：按 F → 选关卡 → 打完结算 → 点一次「再来一次」，
   确认直接进第二场；再打一场，确认能连续循环。有「快速开始」也点一次。
3. **主角在队换人**：把主角放进队伍，换掉一个队友再换回来；确认队伍和场景
   都变化，重登后保持。
4. **命途切换**：切主角/三月七命途；确认立绘、技能、队伍同步变化；重登后保持。
   日志应出现 `avatar path changed: base=... path=...`。
5. **皮肤切换**：给三月七穿 `1100101`，确认立绘、头像和队伍模型变化；再点脱下，
   重登后保持。日志应出现 `avatar skin changed: avatar=1001 skin=1100101`。
6. **指南提示**：进世界后先别按键，看是否**没有**「G 多层韧性」/「欢愉命途」。
   如果还出现，按 G → 关闭 → 再按 G……记录第几轮消失、重登是否回来。
7. **未知命令**：正常关游戏/停服务端后，服务端 stdout 末尾会打印
   `unknown commands: N distinct / M packets`；报告里也会显示「未知命令」数量。
8. **秘技点**：连按秘技 6 次以上。每次客户端先发 1498，服务端补点靠
   `SyncLineupNotify`；`unlimited` 下始终满，`refill` 约 5 秒 1 点，`normal` 5 次耗尽。
9. **混沌回忆回归**：传送进大厅 → 点水晶 → 编队 → 开始挑战 → 打怪 → 星数结算 → 退出。
   确认回到大厅而不是初始世界；日志顺序见 §2 第 10 项。

完成后回 PowerShell 按 **Enter**。

## 5. 回传什么、报告怎么看

回传：

- `logs\test\<run>.report.md`
- 三张截图（`<run>-1.png` / `-2.png` / `-3.png`）
- 一句主观结果：出生点/战斗/挑战是否正常，是否还有 G 提示/弹窗。

报告会自动带：出生点配置、`StartCocoonStage` / `PVEBattleResult` /
`QuickStartCocoonStage` / `ReplaceLineup` / `SetAvatarPath` /
`DressAvatarSkin` / `TakeOffAvatarSkin` / `UnlockTutorialGuide` /
`FinishTutorialGuide` 次数、`Player.log` 异常、服务端日志尾部，以及「闭环检查」：

```text
- 再来一次（至少 2 次 Start/Result）：通过 / 未验证
- 换队：已发生 / 未发生
- 命途切换：已发生 / 未发生
```

关键细节仍可直接看 `logs\packets.log`：

```text
-> ReplaceLineupCsReq ...
-> SetAvatarPathCsReq ...
avatar path changed: base=8001 path=8003
```

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 21000/23301 被占用 | 关掉旧服务端/测试器 |
| 检测到 StarRail.exe | 先完全退出游戏 |
| 一直等登录 | 代理没设系统代理，或 firefly 没拦截登录域名 |
| 截图全黑 | 游戏改无边框窗口 |
| 结算页「再来一次」没反应 | 看服务端是否每场分配新 `battle_id`；日志 `battle info: id=1/2/3...` |
| `--strict` 报 calyx cocoon 缺失 | `world.json.calyx_cocoon_id` 必须在 `battle.json.cocoon_stage_map` 有映射 |
| 快速开始没反应 | 看 `packets.log` 是否有 `QuickStartCocoonStageCsReq`；handler 与 Start 共用逻辑 |
| 皮肤页没有条目 | 看 `GetAvatarDataScRsp.skin_list` 是否为空；检查 `data/skins.json` / `paths.skins` |
| 穿皮肤 retcode=1 | `skin_id` 与角色不匹配；对照 `data/skins.json` 的 `avatar_id` |
| 主角在队时换人无效 | 看 `LineupAvatar.id` 是否用了形态 id；`ReplaceLineup` 是否归一化 |
| 命途按钮不出现/点了没包 | 看 `packets.log` 是否有 `SetAvatarPathCsReq`；先查 `avatar_path_data_info_list` 是否只发同性别形态 |
| 报告里 `FinishTutorialGuide` 为 0 | 正常：客户端不再发完成指南请求，`UnlockTutorialGuideCsReq` 也应为 0 |
| 秘技放几次就灰了 | 确认 `[gameplay].technique_points` 不是 `normal`；每次 1498 之后应有 `sync=True` |
| 秘技点 `/5` 一直是 0 | 检查 `LineupInfo.mp`：`build_lineup()` 会带 `technique_points_max`，`unlimited` 下恒满 |
| 指导「传送」没反应 | 看 `packets.log` 是否有 `enter scene: entry=100000104`；没有则是 handler/场景数据问题 |
| 传送后加载条卡死 | 先看 `Player.log` 是否 `MapNPC:227-400001` NRE（客户端资源问题，重试）；同时检查组统计 oneof 是否填满 |
| 挑战打完怪重生、不结算 | `ChallengeSettleNotify` 没发或字段不全；看日志是否有 `challenge battle result` |
| 结算后回初始世界而不是大厅 | `LeaveChallenge` 没回到进入前场景；看 `leave challenge` 日志 |
| 挑战面板显示 45/45 满进度 | 正常：`star=7` / `taken_reward=42` 抄 pearl，不是真实进度 |

挑战链的根因与修复细节见 [../design/03-终局玩法](../design/03-终局玩法.md) §5。

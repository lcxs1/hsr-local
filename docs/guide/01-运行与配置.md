## 2. 启动链路

```text
run.ps1 / run.bat
  → .venv\Scripts\python.exe -m hsr
  → hsr/__main__.py
      → Runtime.load()                  # hsr/runtime.py
          ├─ AppConfig.load()           # config.toml + data/world.json
          ├─ setup_logging()            # 控制台 + logs/packets.log
          ├─ VersionProfile.load()      # versions/<profile>.toml
          ├─ Registry(profile.proto_dir)
          ├─ register_all(router)       # game/handlers/__init__.py
          ├─ Roster / Lua / Prefs / Save / Tutorials / Progress
          ├─ BattleData / EndgameData / SkinBook
          └─ config_check.validate()    # 非 strict 只 warning
      → net.server.start()              # UDP 23301
      → freesr_sync.watch()（可选）      # 文件监视热更新
      → dispatch.app.serve()            # HTTP 21000
```

正常启动输出：

```text
================================================================
  hsr-local · OSBETAWin4.6.54 · profile=4.6.54 · uid=10001
  game   udp://127.0.0.1:23301
  sdk    http://127.0.0.1:21000
  srtools POST http://127.0.0.1:21000/srtools  (... watch=on)
  kcp    u32_le_token  unknown=empty_rsp
================================================================
```

启动客户端前，代理必须把登录域名指到 `127.0.0.1:21000`：

```powershell
cd E:\SiFu\HSRSiFu
Start-Process .\firefly-go-proxy.exe -ArgumentList `
  '-e','E:\SiFu\HSRSiFu\StarRail_4.6.54\StarRail.exe','-p','9978' -Verb RunAs
```

UAC 点“是”。停在 HoYoPass 登录窗、一直不连接，通常是系统代理没开或没指向 `127.0.0.1:9978`。

> 常用调试开关：`-m hsr --strict`（配置错误直接退出）、
> `-m hsr --profile <name>`（临时换 `versions/<name>.toml`）、
> `-m hsr --config <path>`（临时换配置文件）。

| 键 | 默认 | 说明 |
|---|---|---|
| `technique_points` | `unlimited` | 秘技点策略：`unlimited` 不消耗 / `refill` 定时恢复 / `on_empty` 扣到 0 回满 / `normal` 只扣不回 |
| `technique_points_max` | `5` | 客户端最多画 5 个菱形 |

### 3.6 `[endgame]`

终局玩法口径（[AGENTS.md §5](../../AGENTS.md) 的 A 模拟器口径）。只影响挑战列表与解锁，不改协议形态；
详细设计见 [design/04](../design/04-混沌回忆模拟器口径.md)。

| 键 | 默认 | 说明 |
|---|---|---|
| `moc_group_id` | `0` | 混沌回忆用哪一期（一组 = 一期 10/12 层）。`0` = 按 `data/vendor/srtools-*/endgame_index.json` 的 `BeginTime/EndTime` 自动选当前赛季（2026-11-11 = `1036 物竞天择`）；写数字则强制 |
| `unlock_all` | `true` | 所有层按满星下发（客户端视为已解锁、可重打，pearl-sr 做法）；`false` 需要通关历史（M3 才落库） |
| `advance` | `inplace` | 阶段切换方式：`inplace` 同场景换组（默认，参考实现）/ `scene` 重建 `SceneInfo`（A/B 探针，4.6.54、4.7.0 下半黑屏就是这条路）/ `client` 等客户端自己发 `StartChallenge`（pearl 流程）。旧值 `refresh`/`none` 仍可读 |
| `lobby_entry` | `0` | 「传送」进忘却之庭时换成哪个入口（`0` = 用客户端请求的 `100000104`）；`100000352` 是参考实现用的观景车厢 |
| `lobby_teleport` | `scene` | 「传送」进大厅（plane 10000）要不要真切场景。两个客户端都会在加载 floor 10000000 时挂在配置残缺的地图 NPC 上（`MapNPC:227-400001` → `MapNpcDef.get_ConfigEntityPath` NRE → SDK 弹框 → 会话关闭），但**不是每次都挂**（21:02 成功过一次）。`scene` = 照常切（默认，卡了重启客户端重试）；`ignore` = 不切、只重发当前场景（不会卡，但大厅 UI / 水晶也进不去） |
| `lobby_props` | `crystals` | 大厅报哪些场景组：`all` / `crystals`（只报 `prop_id >= 100000` 的展台）/ `none`。装饰组带那个坏 NPC |
| `lobby_grace_seconds` | `0` | 登录后多少秒内点「传送」把场景推送压后。真机已证伪（与时间无关），保持 0 |
| `group_list` | `all` | 真机探针：`all` 发全部 109 个组（现状）/ `rewards` 只发领过星数奖励的组（DanhengServer 写法，新号 = 空） |
| `send_max_level` | `false` | 真机探针：额外发 `max_level_list`（Himeko-Nova-SR 的写法，字段语义未确认） |

改 `group_list` / `send_max_level` 后重启服务端、登录看忘却之庭右侧卡片数；一次只改一个。

## 4. 版本 profile


一个服务端进程只服务一个客户端 build。`config.toml [server].profile` 选择默认 profile，
临时切换用 `--profile`：

```powershell
.\.venv\Scripts\python.exe -m hsr                    # 默认 4.6.54
.\.venv\Scripts\python.exe -m hsr --profile 4.7.0    # CN 4.7.0（需 features.local_cdn=true）
```

`[field_aliases]` 用来抹平不同 build 的字段改名，例如
`asset_bundle_url_b ↔ asset_bundle_url_android`、`lua_version ↔ mdk_res_version`。
升级流程见 [../reference/02-开发与版本更新](../reference/02-开发与版本更新.md) §6。

## 7. 热更新与 Lua 控制台

### 7.1 freesr 热更新（SR Tools 网页）

服务端运行中即可改角色/光锥/遗器，不用重启。

1. 服务端启动日志里应出现 `srtools POST http://127.0.0.1:21000/srtools`；
2. 浏览器打开 <https://srtools.punklorde.org/>，先「加载数据」：
   从 <http://localhost:21000/srtools/export> 下载当前配置再导入
   （否则网页里是它自己的默认数据，遗器/光锥可能是空的）；
3. 「连接设置」→ 连接类型选 **RobinSR** → 「连接 PS」：
   第一次是探活（不带 `data`，服务端回 200），状态变「已连接」；
4. 再点「同步」，整份配置 POST 到 `/srtools`，服务端落盘并热更新；
5. 服务端日志：`freesr hot reload: 99 avatars / 418 relics / 87 lightcones ... pushed to 1 session(s)`。

**防误清空**：网页没先「加载数据」时推过来的遗器/光锥是空数组，服务端会 400 拒绝；
确实要清空用 `POST /srtools?force=1`（或 `push_freesr.ps1 -Force`）。

直接覆盖文件也可以（`features.freesr_watch` 默认 2 秒一拍）：

```powershell
copy <新文件> data\freesr-data.json
curl.exe -X POST http://127.0.0.1:21000/admin/freesr/reload   # 或立刻触发
```

推送顺序：删旧 `unique_id` → 遗器 → 光锥 → `avatar_sync` →（阵容变化时）
`SyncLineupNotify`。网页的 `battle_config` 只落盘，**不参与战斗**。
细节和坑见 [../design/02-玩法与数据](../design/02-玩法与数据.md) §12.2 与
[03-交接与排障](03-交接与排障.md) §3 第 16 条。

### 7.2 Lua 控制台

`lua/main.lua` 在下一次心跳时下发给客户端：

```lua
-- exec=tt
CS.UnityEngine.Debug.Log("[dsh] hello")
```

- `tt` = 只执行一次（服务端改成 `ft`）；`tf` = 每次心跳都执行；
- 输出到客户端的 `Player.log`：4.6.54 在 `...\Cognosphere\Star Rail\`，
  4.7.0 CN 在 `...\miHoYo\崩坏：星穹铁道\`（路径表见 §1）。

```powershell
python -m hsr.tools.lua_console push probe.lua
python -m hsr.tools.lua_console push probe.lua --always
python -m hsr.tools.lua_console status
```

### 8.1 注释与代码约定

1. **handler 和 service 分开**：handler 只收请求/回响应/决定推送顺序；
   数据逻辑放 service（如 `BattleData`、`Roster`、`SaveStore`）。
2. **注释只写“为什么”**：不变量、客户端限制、踩过的坑、魔数出处；
   不写“把 X 赋给 Y”。正例：`battle.next_battle_id`（复用 `battle_id` 会让
   「再来一次」停在结算页）、`scene.build_map_info`（`lighten_section_list` 为空
   → 整张地图全黑）。
3. **注释里引用的路径/符号必须存在**；引用 docs 带篇号和小节
   （`docs/design/01 §3.3`），改了协议行为就同步改锚点。
4. **模块 docstring 是硬要求**：`hsr/` 下每个文件开头都要有一句“这个模块负责什么”。
5. **生成物永不手改**：`hsr/protocol/gen/`、`proto/hsr.desc` 只能由
   `scripts/gen_proto.ps1` 重新生成。
6. **ruff 必须过**；不要为了让检查通过而改规则或加 `noqa`。
7. 一行的 getter / `__dunder__` 不加 docstring；`net/kcp.py` 是第三方移植，
   只在文件头做结构性说明。

## 9. 启动常见问题

| 现象 | 处理 |
|---|---|
| 21000/23301 被占用 | 关掉旧服务端；`Get-NetTCPConnection -LocalPort 21000 -State Listen` 找 PID |
| 一直停在 HoYoPass | 代理没拦截 HTTPS：确认系统代理 `ProxyEnable=1` 且指向 9978 |
| 一直等登录 | 登录域名没指到 21000；看 `logs\packets.log` 有没有 HTTP 请求 |
| `--strict` 报 calyx cocoon 缺失 | `world.json.calyx_cocoon_id` 必须在 `battle.json.cocoon_stage_map` 有映射 |
| 客户端登录很慢 | 正常约 30–45 秒进世界，自动化等够 |
| 改完配置不生效 | `config.toml` 只读一次，重启服务端 |
| 中文 PowerShell 脚本报错 | `.ps1` 必须 UTF-8 BOM，头三字节 `EF BB BF` |
| 截图全黑 | 游戏改无边框窗口 |

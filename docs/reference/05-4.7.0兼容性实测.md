## 3. 资源校验（hotfix）

客户端在 `query_gateway` 之后、连游戏服之前会校验资源清单；清单 URL 来自 hotfix，键为 `CNPRODWin4.7.0`。
社区 hotfix 表（pearl / echium / Himeko 上游）当天还停在 4.6.54。

实测过的四条路径：

| 尝试 | 现象 |
|---|---|
| 用 4.6.54 的 hotfix 条目 | 「正在下载数据资源」，从官方 CDN 拉 4.6.53 的块写进 `Persistent` |
| `features.send_hotfix = false` | 「资源下载失败，是否重新尝试」 |
| 伪造 `output_<id>_<假 hash>` | 清单 404，同上 |
| **本地清单回放** | **通过**，客户端连上游戏服 |

本地清单回放：hotfix 的 asb/design/lua 基址指向本机小 HTTP 服务，按文件名把客户端**自己**安装里的文件回给客户端。
客户端只取 3 个顶层清单（`M_ArchiveV`、`M_Design_ArchiveV`、`M_LuaV`），版本一致就不再下载。

两个要点：

1. `M_Design_ArchiveV` 必须指向客户端实际安装的设计清单（`DesignV_2de2272805b39ab73f9d901e64b6ffc5`）；
   `StreamingAssets` 里的 `DesignV_9482…` 是安装期 stub，缺中文 textmap，客户端会 `TextmapExcelTable` NRE；
2. 回放只读客户端目录；客户端自己会写 `*_cache.bytes`，属正常行为。

### 3.1 清单分隔符必须是「一行一个 JSON」

第一版回放把清单用 `..` 拼成一行，**预登录的资源校验能过、登录也能过**，但进世界前客户端会再跑一次
版本更新，用严格 JSON 解析整份 `M_Design_ArchiveV` 时报：

```text
[VersionUpdate] BundleArchiveFile::_ParseOneJsonInfoFromJson, error is Additional text
encountered after finished reading JSON content: .. Path '', line 1, position 214.
```

于是判定设计档案需要重下，弹出「任务资源管理 · 当前账号需要下载必要的任务资源（27987.72MB）」，
客户端停在弹窗、不再发心跳（15 s 后服务端 `session closed (heartbeat timeout)`）。

正确格式就是客户端 `StreamingAssets` 里的原样：**每行一个 JSON 对象 + CRLF**（见 `local_cdn._SEPARATOR`）。
改成 CRLF 后，同一份清单只有 `ContentHash/FileSize` 两处被改写，其余字段与安装文件逐字节一致，真机通过。

> 排查时还要注意：上一轮失败会在客户端留下 `Persistent/DesignData/Windows/M_Design_ArchiveV_cache.bytes`
> （客户端把下载到的清单缓存下来）。重试前删掉这个缓存文件，否则客户端会继续用旧的 `..` 版本。

## 4. 第一处代码阻塞点

客户端读到 `GetArchiveDataScRsp`（cmd 2319）的空 body 后：

```text
NullReferenceException
  at RPG.Client.AvatarArchiveData.Sync (...)
  at RPG.Client.ArchiveModule._OnGetArchiveDataScRsp (...)
```

协议定义（4.6.54 表）：

```proto
message GetArchiveDataScRsp {
  ArchiveData archive_data = 1;
  uint32 retcode = 10;
}
```

空 body 意味着 `archive_data` 未设置（null），客户端直接解引用。修法是给这个命令加 handler，
返回 `archive_data = ArchiveData()`（空但存在）。这类“空回包 → NRE”在 4.7 客户端可能不止一处，
需要按 `Player.log` 逐个补。

## 7. 局限

1. **真机已过登录/进世界/战斗（§5.1）**；4.7 新皮肤「群星乐透」未解锁（缺 4.7 `AvatarSkin` 表的 id），

2. 数据表仍是 4.6.54 的，4.7 新内容（新角色、新活动、新皮肤）没有；
3. 本地清单回放要求客户端安装完整；`Persistent` 为空的客户端会因缺设计数据 NRE；
4. 本轮没有取官方网关的真实 hotfix 条目（当时 §10 是硬红线）；2026-11-11 起
   [AGENTS.md §6](../../AGENTS.md) 允许缺条目时取一次（默认关闭），真实 CDN 条目可自行拉取，本条未复测；
5. 4.7 客户端对未实现模块的空回包仍会打 NRE（本轮 `Player.log` 有 14 类，来自 PetMarble/RogueTourn/
   Alley/TrainParty/CycleScore 等），不影响进世界与战斗，但会刷日志；按需逐个补空子消息。

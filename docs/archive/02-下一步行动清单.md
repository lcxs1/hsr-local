### A3. 生成 Python 代码

```powershell

New-Item -ItemType Directory -Force proto\gen | Out-Null
& $protoc -I proto --python_out=proto\gen --pyi_out=proto\gen `
```

生成后写一个 `proto/gen/__init__.py`（空文件即可），并在 `pyproject.toml` 里把 `proto/gen` 加进包路径（或把生成文件放 `src/hsr/protocol/gen`）。

### A4. 先写三个纯离线组件（不碰网络）

1. `net/frame.py`：帧读写 + 单测（用 `golden_samples` 里的原始帧）。
2. `protocol/registry.py`：名字↔id、`CsReq->ScRsp`、去尾部数字回退。
3. `protocol/codec.py`：`decode_any(cmd, body)`（动态池）+ `dump()`。

**验收**：写一个 `python -m hsr.tools.decode --capture ...`，能把 `tap-20261101-155841.bin` 里的帧全部解出来，结果与 `golden_samples_4.6.54.txt` 对得上。

### A5. 再写传输（KCP 双模式）

1. `net/kcp.py`：移植 ppSR 实现；把 8 字节会话标识抽成 `ConvCodec`。
2. `net/handshake.py`：20B 解析/构造。
3. `net/session.py` + `net/server.py`：UDP 收包、KCP update、路由。
4. `tools/kcp_probe.py`：两种编码各自解同一段抓包，输出判定。

**验收**：用 `tools/probe.py` 向本机发 `PlayerGetTokenCsReq`，收到 `uid`；再用真实客户端跑一次，日志里出现 5/74/46/45。

> 如果真实客户端在握手后被丢弃（日志有握手、无后续帧），切换到另一种 `conv_mode` 再试。

### E2. 第二轮修复（弹窗 / Lua / 地图）

**1) 进游戏时弹「无尽膨胀奇物·位面规则」等窗口 —— 已修复并验证**

- 原因：客户端用 `ServerPrefs`（cmd 6174 / 6105）保存"已读"标记。我们之前对
  `GetAllServerPrefsDataCsReq` 回空、`UpdateServerPrefsCsReq` 直接丢弃，于是**每次登录都被当成首次登录**，客户端反复弹引导/公告窗。
- 修复：新增 `hsr/game/services/prefs.py` + `handlers/prefs.py`，把 prefs 持久化到
  `saves/server_prefs.json`（base64）。首次登录采集到 10 条（id 3/8/9/10/21/301/304/3101/3102/3305）。
- 验证：第二次登录（prefs 已存在）直接进世界，**没有再弹窗**。

**2) Lua 控制台其实一直是坏的 —— 已修复并验证**

- `on_heartbeat` 里 `rsp.download_data = pb.ClientDownloadData(...)` 触发
  `AttributeError: Assignment not allowed to message field`，心跳因此回空包，脚本从未下发过。
- 改为 `rsp.download_data.CopyFrom(...)`。
- 验证：注入 `CS.UnityEngine.Debug.Log("[dsh] lua-alive")`，`Player.log` 收到输出；
  进一步枚举到 `CS.RPG.Client.UIManager` 实例，但 XLua 只暴露了 16 个常量字段、
  沙箱 `_G` 只有 161 个名字，**无法从注入脚本里调用地图 UI**。

**3) 地图（导航）打不开 —— 已按 pearl-sr 补齐数据，但未能实测**

- 参考资料：`pearl-sr/gameserver/src/services/scene.zig::onGetSceneMapInfo`。它返回
  `unlocked_teleport_list`（该 plane 的 teleportId）、`maze_prop_list`、
  `maze_group_list`、`lighten_section_list`（0-100 / 10000-10050 / 20000 / 30000-30020）。
- 已改：`build_map_info()` 补上上述字段，teleport id 用 20313 的真实值
  `2031301/2031302/2031303`（来自 pearl `res.json` 的 teleports，与 MapEntrance id 一致）；
  配置新增 `world.teleport_ids`。
- **未能实测的原因**：客户端以管理员权限运行（StarRail.exe 清单要求），而本机
  DSH 进程是 Medium 完整性，Windows UIPI 会拦截注入的鼠标事件
  （`SetCursorPos` 返回 false、`SendInput` 鼠标无效；键盘不受影响），
  所以无法点「导航」。echium / ppSR 干脆没实现 1461，这解释了为什么它们的地图也是死的。
- 下一步验证方式（需要真人点一下）：启动服务端与游戏 → Esc → 点「导航」→
  看是否打开；同时 `logs/packets.log` 里应出现新的 `GetSceneMapInfoCsReq (1461)`，
  `Player.log` 里若出现异常则按异常补字段。


启动方式与已知限制见项目内 `README.md`。
